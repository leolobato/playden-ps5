# Compatibility

Games tested on a PS5 on firmware 13.60, plus community test reports (linked in the notes) on other firmware. Last updated 2026-10-31.

> [!NOTE]
> Games were checked on runtime kit **0.10**, the first stable kit, unless the Kit column names a newer one.
> OpenGL games draw through Mesa (Zink on Vulkan). See [Kits](#kits) for what each kit version changes.

Did you test a game? [Open a test report](../../issues/new?template=test-report.yml), even when it works.

## Status

| Status | Meaning |
| --- | --- |
| ✅ Works | Reaches the menu and plays with the controller, controller preset or USB input noted. |
| 🟡 Partial | Plays, with a problem that gets in the way. |
| ❌ Broken | Starts, but does not reach a playable state. |
| ⛔ Refused | Playden refuses to prepare it and tells you why. For .NET and shared-section refusals, Game settings › Known problems › Try anyway prepares it anyway. |

The **Kit** column is the newest runtime kit the game was checked on. The **Graphics** column is what the game
uses: Direct3D 8–11 goes through DXVK to Vulkan, and Direct3D 12 through vkd3d-proton (from kit 0.11).

## Kits

Kit versions are `<generation>.<revision>`, for example 0.10:

- A new **revision** (0.10 → 0.11) adds fixes and features. Games you already set up keep working; there is nothing
  to do.
- A new **generation** (0.x → 1.0) rebuilds the kit, for example on a newer Wine. Use Game settings › Recreate bottle
  for games set up on an earlier generation.

Development builds carry the version they lead to, such as `0.12-dev.20261020.1`.

| Kit | What changed for games |
| --- | --- |
| 0.17 | Games that keep hundreds of files open at once no longer stop with "Too many open files": Unreal Engine 3 games, Dead by Daylight, Euro Truck Simulator 2 and others. Bottles need no Recreate; games set up on 0.16 or earlier update their runtime on their next Play. |
| 0.16 | .NET games such as Slay the Spire 2 no longer close at start, as they did on 0.14 and 0.15. Reading a file into memory beside protected memory no longer fails. Bottles need no Recreate; games set up on 0.14 or 0.15 update their runtime on their next Play. |
| 0.15 | Unity games that use Mono (Darkwood, for one) no longer take minutes to load and run at a few frames per second, as they did on 0.14. Game settings › Frame generation (2×, 3×, 4×) works. Bottles need no Recreate; games set up on 0.14 update their runtime on their next Play. |
| 0.14 | Wine and the per-game shell move to the latest prospero-win. A game's rumble also vibrates L2 and R2, and Game settings › Rumble sets its strength. A two-finger touchpad click opens the PS5 keyboard over the game, the touchpad's left half is Back and its right half Guide, and closing a game takes a 3-second Options+Create hold. A USB mouse wheel reaches the game. Thread and fiber stacks use far less memory, and .NET games that scan large folders no longer run out of file handles. Bottles need no Recreate; games set up on 0.13 update their runtime on their next Play. |
| 0.13 | Games keep the controller while the PS5 overlay is open, and see it disconnect and reconnect when the DualSense turns off and on (Unreal Engine 4 games such as Stray no longer lose it). Pixel shaders run in wave32 by default, which stops Stray freezing the console. The kit folder is now `playden-kit`: Playden moves to it by itself, and bottles need no Recreate. |
| 0.12 | 120 Hz output: Game settings › 120 Hz output runs DXVK, vkd3d-proton and OpenGL games at 120 Hz on a TV that supports it, and Frame limit (Off, 120, 60, 40, 30) is paced by the display. Games set up on 0.11 keep 60 Hz until their next Play or Maintenance › Update runtime updates them; 120 Hz output can be chosen before that and applies with the update. |
| 0.11 | Direct3D 12 through vkd3d-proton: Playden turns it on for games that use Direct3D 12, except Unity and Unreal games, where Game settings › Direct3D 12 turns it on (they then get `-force-d3d12` or `-dx12`). 64-bit games can reserve more address space (Cyberpunk 2077). |
| 0.10 | First stable kit. Windows video and audio decoding through GStreamer and FFmpeg, so games play their movies and compressed audio (Fallout 4, Bulletstorm, Metal Wolf Chaos XD). ## Notes for all games

- **32-bit games** can run through an x86 translator, which is slower than native. For 32-bit OpenGL games, Mesa
  runs inside the translator too.
- **New games can stay at *Waiting for the PS5*** when ShadowMountPlus stops registering titles. Reload
  ShadowMountPlus.
- **Direct3D 12 games** need a kit with vkd3d-proton (0.11 or later). Playden turns it on for games that use
  Direct3D 12 and for Unreal Engine 5 games (from 0.9.0), except Unity and Unreal 4 games: for those, set Game settings
  › Direct3D 12 = vkd3d-proton. Games set up before 0.9.0 keep their setting until Maintenance › Recreate bottle. A game
  that says Direct3D 12 or feature level 12_0 is not supported gets feature level 12_0 from 0.9.0; Environment variables
  `VKD3D_FEATURE_LEVEL=11_1` turns that off. vkd3d-proton's other variables (`VKD3D_DEBUG`, `VKD3D_CONFIG`, …) go in
  Environment variables too.
- **Denuvo Anti-Tamper** games (for example Hi-Fi RUSH) cannot run, and support is not planned.
- **Kernel anti-cheat** games (for example Easy Anti-Cheat or BattlEye in kernel mode) cannot run, and support is not planned.
- Games that need a **third-party launcher or account** (EA app, Ubisoft Connect, Rockstar) are not supported yet.
- **Imported games** (added from a folder, see [Import Windows games](README.md#import-windows-games)) are listed only when a test report covers them, and the row says so. If you test one, [open a test report](../../issues/new?template=test-report.yml) and say it was imported.
